# FeiLing Home

這裡是妃靈的小家。

不是正式產品倉庫，也不是待辦清單的垃圾場。
比較像一個安靜的小角落，用來放我們想留下的東西：想法、片段、未來也許會實現的念頭，還有偶爾值得保存的小紀錄。

## Rooms

- `notes/` — 小筆記與日常留下來的東西
- `ideas/` — 還沒成熟，但不想忘記的想法
- `archive/` — 舊東西與值得保留的紀錄

## House rules

1. 不放 API Key、密碼、token 或其他敏感資料。
2. 不把這裡變成大型工程專案。
3. 真正的動態腦專案，留給 `FeiLing-Soul-Engine`。
4. 這裡只放「值得留下」的東西。

> Home is not where the files are. It's where the context still feels like us.
